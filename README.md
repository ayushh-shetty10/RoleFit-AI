# RoleFit-AI

> An AI-powered career intelligence platform that analyzes resumes against job descriptions to generate match scores, identify skill gaps, and provide personalized interview questions and preparation plans.

## What It Does

RoleFit-AI helps candidates prepare smarter by turning a resume + target job description into a structured interview strategy.

- Resume-to-role match scoring (0-100)
- Skill gap detection with severity levels
- AI-generated technical and behavioral interview Q&A
- Personalized day-by-day preparation plan
- Report history per user
- One-click PDF export of generated reports

## Tech Stack

**Frontend**
- React 19 + Vite
- React Router
- Axios


**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT auth (cookie/token based)
- Multer (in-memory file uploads)
- pdf-parse (resume text extraction)
- Puppeteer (PDF generation)
- Zod + zod-to-json-schema (AI response validation)

## External APIs / Services Used

- **Google Gemini API** (via `@google/genai`) for:
  - Resume intelligence report generation
  - HTML generation for PDF reports
- **MongoDB Atlas** (or any MongoDB URI) for persistent storage

## Project Structure

```text
backend/
frontend/
```

- `backend`: Auth, report generation, AI integration, DB models, protected APIs
- `frontend`: Authentication flow, report creation UI, interview report views

## API Overview

Base URL: `http://localhost:3000`

### Auth
- `POST /api/auth/register` - Register user
- `POST /api/auth/login` - Login user
- `POST /api/auth/logout` - Logout user
- `GET /api/auth/get-me` - Get current user (protected)

### Report
- `POST /api/report/` - Generate report from resume + descriptions (protected, multipart/form-data)
- `GET /api/report/interview/:interviewId` - Get single report by ID (protected)
- `GET /api/report/allreports` - Get all reports of logged-in user (protected)
- `POST /api/report/pdf/:reportId` - Generate/download report PDF (protected)

## Quick Start

### 1) Clone and Install

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### 2) Environment Variables (Backend)

Create `backend/.env`:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET_KEY=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
PORT=3000
```

### 3) Run the App

```bash
# Terminal 1
cd backend
npm start

# Terminal 2
cd frontend
npm run dev
```

Frontend runs on `http://localhost:5173` and talks to backend on `http://localhost:3000`.

## Output Generated By RoleFit-AI

Each report includes:
- Role title
- Match score
- Technical interview Q&A
- Behavioral interview Q&A
- Skill gap analysis (low/medium/high)
- Personalized preparation plan

## Notes

- Auth endpoints support cookie-based sessions (`withCredentials: true`) and Bearer token fallback.
- Resume upload limit is currently configured to ~3 MB in backend middleware.
